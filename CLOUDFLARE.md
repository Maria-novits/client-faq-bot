# Бесплатный запуск в Cloudflare

Рабочая программа — `worker.mjs`. Она принимает сообщения Telegram через защищённый webhook. Ноутбук не нужен. Windows-скрипт и Dockerfile — альтернативный старый способ запуска; одновременно с Worker их запускать нельзя.

## Созданные ресурсы

- Worker: `pyatynailcreatorbot`.
- Адрес: `https://pyatynailcreatorbot.mbengalskaya.workers.dev`.
- D1: `pyatynailcreatorbot-db`, имя подключения в Worker — `DB`.
- Три кнопки: Запись, Прайс, Адрес. Заявка мастеру — /contact.

## Закрытые настройки

В Settings → Runtime variables and secrets создать три записи **типа Secret**:

- `BOT_TOKEN`: токен BotFather.
- `SETUP_CODE`: придуманный владельцем секретный код, минимум 16 латинских букв/цифр. Не использовать пароль другого аккаунта.
- `WEBHOOK_SECRET`: другой случайный код, минимум 32 латинские буквы/цифры. Он защищает входящие сообщения от подделки.

Секреты не добавлять в GitHub, переписку, скриншоты или обычные текстовые переменные. Сохранить изменения кнопкой Deploy, если Cloudflare её показывает.

Затем открыть `/setup` по адресу Worker. Ввести **SETUP_CODE**, не токен. Нажатие «Подключить Telegram» создаёт таблицы, проверяет имя бота и подключает Telegram. Если открыт локальный скрипт бота, сначала остановить его.

В личном чате с @pyatynailcreatorbot отправить `/owner СЕКРЕТНЫЙ_КОД`, подставив SETUP_CODE. После подтверждения отправить /start. Без привязки владельца клиенты видят сообщение о настройке.

Проверить все три кнопки, неизвестный вопрос и /contact с тестовыми данными. Проверить ответы с телефона при выключенном ноутбуке. До этой проверки запуск не считается завершённым.

## Хранение и ограничения

Токен хранится только в Cloudflare Secrets. База хранит Telegram ID получателя, незавершённые заявки (до суток) и номера обработанных сообщений (до двух суток). Просроченные записи очищаются при получении следующего сообщения. После отправки заявки данные удаляются из таблицы sessions; копия остаётся в Telegram мастера и может сохраняться в резервных копиях базы.

Повторно доставленные обработанные сообщения не обрабатываются снова. При сетевом сбое в момент отправки возможен повтор уведомления: у заявки указан номер и чат для сверки.

Это бесплатный тариф с лимитами, не гарантия бесперебойной работы навсегда. Не включать платный тариф без согласования. При превышении бесплатных квот бот может временно перестать отвечать.

Ответы в worker.mjs встроены из faq.json. После изменения faq.json обновить блок FAQ в worker.mjs и опубликовать код Worker снова. Изменения только в GitHub не публикуются автоматически: пока используется ручное развёртывание через Cloudflare.

## Проверка кода

Node.js 24: `node --test worker.test.mjs`. Проверяются защита webhook, привязка владельца, три кнопки, FAQ, проверка телефона, пересылка контактов, отмена и повторная доставка сообщения. Тесты не обращаются к настоящему Telegram.
