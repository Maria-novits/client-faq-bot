# Бот для клиентов

## Первый запуск

1. Откройте в Telegram официального [BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, укажите название и свободное имя, заканчивающееся на `bot`.
3. BotFather выдаст токен — секретный ключ. Не отправляйте его другим людям и не публикуйте.
4. В этой папке дважды нажмите `start.cmd`. Дополнительные программы устанавливать не нужно: используется Windows PowerShell.
5. Вставьте токен в открывшееся окно и нажмите Enter. При вводе символы не видны.
6. Окно покажет ссылку на вашего бота и команду `/owner ...`. Откройте бота **в своём Telegram** и отправьте эту команду. Она привяжет пересылку контактов к вам.
7. Напишите «Есть прайс?», «Свободные окошки?» и «Где вы находитесь?».
8. Отправьте /contact и пройдите три шага. Заявка придёт вам в этот же чат.

## Каждый следующий запуск

Дважды нажмите `start.cmd`. Окно должно оставаться открытым. Компьютер должен быть включён, не спать и иметь доступ к интернету. Это первая локальная версия; для круглосуточной работы позже понадобится постоянный сервер.

Остановка — Ctrl+C или закрытие окна. Запускайте только одну копию.

## Тексты и данные

Готовые ответы находятся в `faq.json`. После изменения перезапустите бота. Диапазон дат — заготовленный ответ, бот пока не ведёт календарь и не бронирует время.

`settings.json` содержит секретный токен и ваш Telegram ID. `state.json` хранит незавершённые заявки и отметку обработанных сообщений. Оба файла создаются автоматически и исключены из Git. Завершённая заявка удаляется из локального состояния после отправки мастеру; сообщения остаются в Telegram. Не передавайте эти файлы другим людям.

Для смены бота или получателя остановите программу и удалите `settings.json` и `state.json`, затем запустите заново.

## Проверка без Telegram

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\bot.ps1 -SelfTest`

`preview.html` — демонстрация ответов на компьютере. Она не отправляет сообщения в Telegram и не собирает реальные контакты.

## Облачный запуск

Инструкция для круглосуточной работы без ноутбука: [CLOUD.md](CLOUD.md). В боте три кнопки: «Запись», «Прайс», «Адрес». Контакты принимаются по команде /contact.
