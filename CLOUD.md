# Запуск бота в облаке Railway

Бот работает как постоянный процесс, без сайта и публичного домена.

1. Войти на railway.com через GitHub. New Project → Deploy from GitHub repo → Maria-novits/client-faq-bot.
2. В Variables создать секретные настройки:
   - BOT_TOKEN — токен BotFather, без кавычек.
   - BOT_SETUP_CODE — самостоятельно придуманный секретный код из минимум 16 латинских букв и цифр. Он нужен только для привязки получателя заявок. Не публиковать и не присылать в чат.
   - BOT_DATA_DIR — /data.
3. Подключить постоянный диск (Volume) к этому сервису с Mount Path /data. На нём сохраняются получатель заявок и незавершённые обращения. Токен в файлы облачной версии не записывается.
4. В настройках: Serverless / App Sleeping выключен; одна реплика; Restart Policy — Always; Overlap — 0 (не запускать две копии одновременно). Публичный домен не нужен. Railway использует Dockerfile.
5. Нажать Deploy. Дождаться Running и сообщения «Бот запущен» в логах. Не публиковать содержимое Variables.
6. В своём Telegram открыть @pyatynailcreatorbot и отправить `/owner ВАШ_СЕКРЕТНЫЙ_КОД`, подставив BOT_SETUP_CODE. Команду вводить только в личном чате со своим ботом. Первый человек, знающий этот код, становится получателем заявок.
7. После подтверждения отправить /start. Проверить три кнопки: «Запись», «Прайс», «Адрес». Проверить /contact с тестовыми данными: заявка должна прийти вам.
8. Остановить локальную копию на ноутбуке, если она была запущена. Выключить ноутбук и проверить бота с телефона.

Кнопка «Запись» показывает диапазон свободных дат; /contact передаёт заявку мастеру. Это не автоматическое бронирование времени.

Хостинг расходует ресурсы и может требовать оплаты. До подключения тарифа проверить стоимость и согласовать бюджет. Пробный кредит ограничен по сроку и сумме, это не бессрочный бесплатный запуск. При исчерпании кредита/лимита, сбое сервиса или проблемах оплаты работа может остановиться.

Для смены токена изменить BOT_TOKEN в Variables и перезапустить сервис. Для смены получателя остановить сервис, удалить только settings.json на диске /data, изменить BOT_SETUP_CODE и повторить привязку. Не удалять весь диск.
